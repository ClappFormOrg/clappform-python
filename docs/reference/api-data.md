# Data: `cf.data`

The generated methods of the `cf.data` family, one class per proto service.
Every method follows the [calling convention](api-families.md#calling-convention).
`cf.data.collection()` and `cf.data.query()` are the DataFrame handles,
documented under [DataFrame surface](dataframes.md).
